# SBL Site

Stable post-Phase 7 build of the SBL dashboard.

## Included
- Main dashboard and league pages
- Rosters
- Free Agency
- Match Prep
- Stats
- Season
- Draft
- Admin
- Shared Pokémon, Supabase, replay, roster, trade, stats, and league services
- Phase 7 responsive UI and performance improvements

## Deployment
This repository is a static site. Upload the contents of this folder to the repository root so files such as `index.html`, `stats.html`, and `match-prep.html` are at the top level.

Keep the existing folder structure (`css/` and `js/`) unchanged.
